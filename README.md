# Nebula

This is the Nebula Monte Carlo simulator for electron-matter interaction. Full
instructions on how to install and use this software are in the
[documentation](https://nebula-simulator.github.io).

Version 1.1.0
Updated by Dian Yu, July 2026:

This repository has been updated, compiled, and tested with the following configurations:
  - WSL2(Ubuntu 24.04 LTS), Intel Core i7-13700KF, 64GB RAM, NVIDIA GeForce RTX 4080 with 16GB VRAM
  - CUDA Compiler 12.6, HDF5 1.10.10, GNU 13.3.0, cmake 4.2.1

Please edit the CMakeLists.txt file to match your local HDF5 installation, CUDA PATH, and GPU architecture if necessary. 
It currently assumes that you have an NVIDIA GPU with compute capability 8.9.
You may consult other sources for more details on how to compile the code if needed.
To see comments, ctrl + shift + f the repository and search for 'Jonathan C' and 'Dian Yu'.

Please see the new capabilities below that have been added:
Electrons now contain z position at generation for escape depth, lineage tag, and event ID. Please change the dtype of the primary electrons:
    
    electron_dtype = np.dtype([
        ('x',  '=f'), ('y',  '=f'), ('z',  '=f'),  # Position
        ('dx', '=f'), ('dy', '=f'), ('dz', '=f'),  # Direction
        ('E',  '=f'), ('origin_z', '=f'),          # Energy and escape depth
        ('px', '=i'), ('py', '=i'),                # Pixel indices
        ('lineage', '=i'), ('event_id', '=i'),     # Event ID and lineage tag
    ])

The event IDs are defined as the following integers:
    0:   Primary creation,
    1:   Elastic scattering,
    11:  Phonon scattering,
    12:  Atomic recoil,
    2:   Fermi sea excitation,
    21:  SE generation with plasmon decay,
    22:  Single SE excitation,
    3:   Sub-bandgap energy loss,
    4:   Inner-shell excitation,
    41:  SE from inner-shell excitation,
    991: Detection,
    992: SE detection,
    993: BSE/TE detection,
    994: Termination,
    995: Mirror,
    996: Refraction without transmission,
    997: Refraction with transmission,
    998: Absorption,
    999: Total internal reflection

The lineage tags are defined as the following integers:
    0:   Primary (assumed to travel with dir.z <= 0)
    1:   BSE (changed from primary once dir.z > 0)
    11:  SE1 (generated by primary)
    21:  SE2 (generated by BSE)
    12:  SE1 2nd generation
    22:  SE2 2nd generation 
    13:  SE1s 3rd generation and beyond
    23:  SE2s 3rd generation and beyond

These new tags are available in a new program "nebula_cpu_all_events.exe" which is single-threaded for easier plotting of electron interactions. 
The prescan function in "nebula_gpu" has been optimized to one loop to significantly speed up the process.
Variable phonon domain can be defined in eV for each material using "--phonon-domain". You may skip to use the default value of 200 eV or specify one per material.
EPSILON in "data_types.h" has been increased by an order of magnitude to suppress electrons that leak from the geometry due to 32-bit precision limits.
Initial material for the primary electrons can now be specified using "--initial-material" flag. Default is -123 for vacuum.
The det files now follow the dtype

    electron_dtype = np.dtype([
        ('x', '=f'), ('y', '=f'), ('z', '=f'),
        ('dx', '=f'), ('dy', '=f'), ('dz', '=f'),
        ('E', '=f'),
        ('origin_z', '=f'),
        ('px', '=i'), ('py', '=i'),
        ('lineage', '=i')
    ])

The evnt files (extended based on deposit output) now follow the dtype

    dtype = np.dtype([
        ('x', '<f4'), ('y', '<f4'), ('z', '<f4'),
        ('E', '<f4'), ('delE', '<f4'),('origin_z','<f4'),
        ('px', '<i4'), ('py', '<i4'),('lineage','<i4'),('event','<i4')
    ])

Example Python scripts for generating the pri files and processing the evnt files will be included in the 'script_examples' folder.
Consult other sources for more details on how to set up the Python environment if needed.
Feel free to develop your own processing scripts based on the new capabilities.
